Baum-Werkstatt

lädt …

Ein Heft für den Baum zusammenstellen: welches Licht an welchem Tag dazukommt, was der Baum nach dem richtigen Code zeigt, welche Lieder er singt. Alles bleibt auf deinem Rechner.

Die Werkstatt lädt. Beim ersten Öffnen holt der Browser Python für den Browser (Pyodide, einige Megabyte); danach liegt es im Zwischenspeicher.
